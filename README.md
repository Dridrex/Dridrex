## Projetos que representam bem meu perfil

### API Middleware ERP/OS

Camada intermediária em Node.js para apoiar integração entre ERP e ordens de serviço, com validação de payload, idempotência, geração de CSV e testes automatizados.

### DRE no Discord

Automação pessoal com Discord, IA local, n8n e PostgreSQL para transformar mensagens curtas em lançamentos financeiros estruturados com aprovação humana.

### Homelab

Ambiente próprio com Docker, Cloudflare Tunnel, PostgreSQL, n8n, Uptime Kuma e outros serviços para estudar infraestrutura, automação e operação real.

### Painel de Clientes

Aplicação full stack com Next.js, TypeScript e Supabase para CRUD, autenticação e experiência responsiva voltada a contexto real de negócio.
